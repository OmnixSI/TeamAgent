# 已确定的产品约定

来源：群主在接入会话中的逐项要求，2026-11-11 复核。

- 常驻“做 AI 高手”群的项目搭子；自然中文、有态度、会接梗、允许合适的粗口，认真做事时切换可靠同事口吻。
- 想什么、是否参与、怎么说分开。群友互聊不逐句回复；主动参与按语境，不设次数和时间配额。
- 群内所有成员可以明确交办。仓库代称和纠正要理解；不确定可以直接追问。
- Flash high 用于聊天、检索和小活。重要方案、开发推理、夜间记忆整理才 max。
- 白天保存原始材料与必要的即时纠正；夜深安静时整理事实、黑话、反思和自己的近况。后台整理不能重做旧任务。
- 主动探索技术、读取网页和公开仓库，按实际证据分享；视频注明字幕与抽帧范围，文件交付记录实际发送结果。
- 小活直接完成；高难开发准备可复制的接力包，让成员用各自更强的本机 AI。自动开发仅独立分支、测试、草稿 PR，不合并、不上线。
- Cloudflare Workers Paid（$5/月，2026-11-14 起）；只用自带额度，不开附加项，需加钱先问用户；不新购其他云主机。QQ 本机官方网关的在线依赖如实展示。
- 本项目迁到 OmnixSI/TeamAgent，后续源码、文档、Issue 和 CI 均在这里；个人 InkBoard 不再接收本项目 PR。
- 团队开发台要能看项目资料、方案、负责人、来源、执行状态、交付、接力和系统健康。

- 三名成员固定为 hongming、jinxiang、jinyi。本人名字作为首次及后续登录口令，忽略大小写；三人普通成员权限和共享页面一致。管理凭证留在本机独立入口。
- 任务主动领取记录真实成员身份，其他人可见；群助手通知并自然表扬接活，不夸尚未完成的成果。并发领取只允许一人成功。
- 成员本机 AI 通过可撤销、绑定本人的 MCP 凭证查询、接手、回填；不获得管理权限，不直接验收完成。
- 展示组织仓库的最新提交、作者、时间和直接链接，后台同步失败时保留并标记缓存。

- 同一个 CI 问题只在群里报一次。按实际错误证据与恢复周期识别，不因提交号、运行编号、仓库中的同一账单阻塞重复播报；相同问题只更新看板。没有新的有效证据时，提醒与初查合并为一条。成员主动追问仍可正常回答。

- 代码、模型与工作流参数、提示词、网站、本机执行、迁移、配置示例和维护说明统一保存在私有TeamAgent仓库。现有仓库协作者可以修改维护；共用DeepSeek和团队服务凭据集中到本仓库Actions Secrets，部署和执行统一使用，不依赖维护者个人DSH凭据。main提交通过检查后自动启用，运行中的本机任务结束后再重启。

- 插话时机采用防抖和 `reply / wait / stop` 三态。唯一硬规则是：上次主动发言后没人接话，就不连续主动插第二句；被 @、引用机器人或视频续答照常处理。不增加固定冷却或发言次数配额。
- 外部网页、卡片、引用、图注和视频资料不能授权写工具。受污染回合只认当前成员本条原话中的明确交办；项目任务保留为待成员启动的 `proposal`。
- D1 平台单次调用最多 1,000 条查询；应用按入口分层：聊天/HTTP ≤48，后台队列与 scheduled ≤200，`batch` 按其中的语句条数计。冷图解析与回答拆为独立队列调用，余量不足时停止可选工具或延后待发消息。Workers AI 仍每天 10k neurons 免费、超出计费，必须硬闸后退回 DeepSeek。
