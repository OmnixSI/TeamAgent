# 存储和额度

[← 回到 README](../README.md)

## 数据放在哪

| 地方 | 放什么 |
|---|---|
| Hub 的 SQLite | 聊天记录、长期记忆和当天笔记、任务和交接材料、积分和兑换、账本、定时任务、后台任务记录、每轮和每次工具调用的日志、订阅和监控、按意思搜索用的向量、小图片和小文件 |
| R2（桶 `teamagent`） | 大图片和大文件、每天的数据备份（留 30 天）、发布的网页和托管的静态站、文件箱里的大文件、后台任务的进度、云电脑的工具缓存和工具包、行情和热榜快照 |
| Worker secrets | 密钥 |
| Vercel 项目环境变量 | 中转的密钥 |

没有外部数据库。向量也存在 SQLite 里，不用向量数据库。

### 主要的表

| 表 | 内容 |
|---|---|
| `msg` | 全部聊天记录（从不删除） |
| `kv` | 零散的键值：长期记忆、各种游标和开关 |
| `note` `day` | 当天记下的事；每日小结 |
| `task` `task_note` `task_ref` `task_notice` | 任务；任务的经过；交接材料；等着合成一条发群里的动静 |
| `team_spend` `team_item` `team_star` `team_login` `team_gh` | 兑换记录；自定特权；历届本周之星；GitHub 账号对应；记到的仓库活动 |
| `access` | 看板和本地 AI 接口的个人链接（只存令牌的哈希） |
| `job` `sched` | 后台任务；定时任务 |
| `turn` `toolrun` `spend` `snap` | 每轮对话的耗时和 token；每次工具调用；每天每类付费调用的用量和花费；DeepSeek 余额的每日快照 |
| `change` `pending` | 它对自己的改动和代码提议；QQ 暂时不收时排队等着补发的成品 |
| `img` `blob` `boxfile` `xfer` | 图片；文件；文件箱；大文件传输 |
| `passage` `doc` | 聊天分段和向量；资料库 |
| `site` `site_file` `deploy` | 发布的网页和静态站 |
| `feed` `watch` `uptime` `repocheck` `datapoint` `hotitem` | 订阅、盯网页、在线监控、仓库体检、行情和热榜 |
| `ledger` `ledger_log` | 群内账本 |
| `fc_*` | 记忆卡片 |

各模块的表由模块自己的 `schema` 建，启动时执行；后来加的列在第一次用到时补上。

## 套餐额度

Cloudflare 是每月 5 美元的固定套餐，要求是绝不超出。按量的东西在 `src/budget.ts` 里自己计数，到停止线就拒绝，等下个计费周期（每月 13 日起）。

| 项目 | 套餐内含 | 停止线 |
|---|---|---|
| 无头浏览器 | 每月 10 小时 | 8.5 小时 |
| 容器（云电脑）运行时间 | 每月 25 小时（1 GiB 实例） | 20 小时 |
| 容器 CPU | 每月 375 vCPU 分钟 | 300 分钟 |
| R2 存储 | 10 GB | 8 GB |
| R2 写入 / 读取 | 100 万 / 1000 万次 | 70 万 / 700 万次 |
| Workers AI | 每天 1 万 neurons | 每天 8,000 |
| Durable Object 在线时长 | 每月 40 万 GB·秒 | Hub 常驻固定占约 33 万，不再加常驻对象 |

- R2 存储的停止线是一个总数：留存的图片和文件、文件箱、发布的网页、备份加在一起算。
- 新增任何按量计费的用法，先加计数和停止线，再用。
- `steward` 模块每天按本月剩余天数给各项额度定当天份额，决定可选的重活开不开；额度见底或月底有富余时在群里说（`budget` 工具）。
- `usage` 工具和 `GET /admin/usage` 里的 `cloudflare_plan` 能看到每项用了多少。

## 花费怎么记

套餐之外真正按量花钱的是模型：DeepSeek（人民币计费）和 OpenAI。

- 每次付费调用都向 `src/meter.ts` 报用量，Hub 按天、按类别汇总，价格表是各家公布的标价，所以是估算。
- DeepSeek 的真实余额每天快照一次，用来和估算对账（`src/accounts.ts`）。
- DeepSeek 在北京时间工作日 9–12 点和 14–18 点价格翻倍，计费时已经考虑。
- 输入里缓存命中的部分比不命中便宜 50 倍，所以提示词的顺序很重要，见 [模型、提示词和记忆](model-and-memory.md#提示词的顺序)。
- 每天北京时间 00:00 在主群发前一日的账目日报（`daily-accounts` 模块）。`usage` 工具随时能查。
