# OpenMausBot 编队工作笔记归档（截至 2026-11-14 20:00 悉尼）

原样复制自群主电脑 `~/Projects/.agent/`（各版本笔记）和 `~/Projects/*.md`（调研、评审、事故报告），只收 Markdown。
没有收：D1 原始导出、群消息回放 JSONL、截图、音频、日志和任何凭据文件。

- `agent-releases/<版本>/`：design（方案）、status（进度流水）、next（遗留）、orders（施工单）、notes。
- `agent-releases/ledger-all/`：`live-state.md` 线上能力盘点，`user-asks.md` 用户需求总账，`status.md` 总进度。
- `reports/`：调研、方案评审、事故复盘。

这些是编队成员自己写的记录，「已完成」「已上线」要以 `/health`、D1 和真实群消息为准。接手说明见仓库根目录 [HANDOFF.md](../../../HANDOFF.md)。
