## 1. 方法与边界

- **执行环境**：用户的 Mac 本机（macOS，非 Local VM），通过本机 shell 与 QQ/Chrome 缓存、wrangler、OpenAI HTTPS API 交互。
- **生产 D1 只读**：用 Vault 里「Cloudflare API token（TeamAgent 部署用）」的私有文件设置 `CLOUDFLARE_API_TOKEN`，执行 `npx wrangler d1 execute inkboard-team --remote --config wrangler.toml --command "SELECT …"`。本轮没有执行任何 INSERT / UPDATE / DELETE / PRAGMA 写操作。
- **原图恢复顺序**：① D1 `message_meta` 里的附件 URL；② 实测 CDN 是否过期；③ 本机 QQ 缓存（`~/Library/Containers/com.tencent.qq/.../nt_data/Pic|Emoji`）；④ D1 `stickers.data` BLOB；⑤ B 站视频页 JSON 的 `pic` 封面。
- **识别调用**：`POST https://api.openai.com/v1/chat/completions`，`model=gpt-5.6-luna`，一条 text + 一条 `image_url`（base64 data URL），`max_completion_tokens=1200`（m383 与 375 因 reasoning 占满而提高到 4000/5000 重跑）。没有设置 temperature（模型默认）。§9 的 6 帧统一 `max_completion_tokens=3000`、`detail=high`、`store=false`，未设 `reasoning_effort`；另做 1 次 `reasoning_effort=none` 的 A/B。
- **计费（先看口径）**：本报告所有金额都是**按公开价计算的支出上限估算，不是已查账单的实际扣款**。公式为 `prompt_tokens × $0.20/1M + completion_tokens × $1.20/1M`；`completion_tokens` 含 `reasoning_tokens`（推理也按输出计费）。官方价页 2026-11-14 核对：输入 $0.20/M、缓存输入 $0.02/M、输出 $1.20/M。
  - **原 11 图轮次**：至少 m383、375 出现 2,816 cached tokens；报告没有逐次记录所有调用的 `cached_tokens`，因此没有用 $0.02/M 重算，全部按 $0.20/M 全额输入计。仅就缓存折扣而言，这个算法偏高；其他计价差异（额度、税费、计价规则）以账单为准。
  - **§9 的 6 帧 + A/B**：`cached_tokens=0`，按 $0.20/M 计算与公开价一致；但仍不是账单实际扣款。
  - 未查账号账单/余额；不能声称“实际扣款就是这个数”。
- **时间**：D1 的 `ts` 与 `outbox.created_at` 均按 **+08** 显示；悉尼 AEDT 为 **+11**，即本报告 D1 时间 +3 小时 = 悉尼时间。截图里的状态栏时间是手机本地时间（悉尼）。
- **不做**：不写生产表、不发群消息、不改仓库、不部署、不下载视频、不把封面当视频关键帧、不用模型自评当人工真值。
- **视频帧（§9 追加）**：只取官方 `pages[0].first_frame` 和 `videoshot` 预览帧；不下载视频流/音频/字幕；`videoshot` 是官方预览帧，不是关键帧，也不是全分辨率。
