## 实现要点（DeepSeek 易错处，照做）
1. 金额：`￥360 / ¥360 / 360元 / 360块 / 三百六 / 三百六十 / -10 / 加10 / 减5 / 10.5` → amount_cents 整数分；“我加10” 的“加”=正数，“减/扣”=负数；中文数字最多支持到万，不会解析 → RecordError('invalid', "金额没看懂：xxx")。
2. 「我/本人/自己」→ actor.name；人名归一：去标点空格、小写后比较（t.o.o.==TOO）；先匹配 ctx.names（群昵称）再匹配本类型已有 person 值，匹配不到才新建。
3. 去重：dedup_key = `${dedupBase}:${行序号}`，INSERT OR IGNORE，返回 duplicated 数。
4. 汇总：summarizeRecords 按 person 分组求和（SQL 走生成列/索引），RC-10 期望 370/50/290/710 这种数字必须来自 SQL，不得由模型算。
5. 私有：visibility='private' 行只有 creator 在 query/summarize/export 里可见，他人计入 hiddenPrivate；**群里**本人查询私有行也只给“你有 N 条私有记录，请到工作台查看”（见 §5.3 可见性规则）。
6. quote→confirm：quoteChange 写 pending_actions(missing='confirm', 10 分钟)，返回 before/after；applyChange 只允许 creator 或 isAdmin；多个候选 → RecordError('ambiguous') 带候选 short id。undoLast 只撤 actor 自己 10 分钟内最后一次。
7. 所有写入同批写 record_events；删除是软删（deleted_at）。导出 CSV 带 UTF-8 BOM、≤500 行 ≤64KB、truncated 标志。
8. 限额 LIMITS 用 §5.3 的常量，超限抛 RecordError('quota')。
