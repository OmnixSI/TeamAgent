## 生成器行为（输出符合 src/self-card-types.ts 的 SelfCard）
文件头 `// Generated by scripts/gen-self-card.mjs; edit config/self-manifest.json instead.`，`export const SELF_CARD: SelfCard = {...}`（import type 自 ./self-card-types）。
1. commit：`git rev-parse HEAD`（失败则 "unknown"）；built_at：ISO 时间。
2. **工具表**：用 esbuild（已是 devDependency）把 src/tools/index.ts 和 semantic.ts 的 baseTools 打包后导入，取真实的工具定义（name、description 首句、switch）。baseTools 在 src/semantic.ts 里定义（`rg -n "baseTools" src/semantic.ts`）；若它没有导出，可以只在生成器里用正则从 semantic.ts 抽 `name: "xxx"`，二选一，选能稳定跑通的，写进笔记。repoTools 来自 src/repo.ts。
3. **清单 config/self-manifest.json** 结构（你来写第一版，覆盖当前 release/SK 代码里所有对用户有意义的能力：回复与推理、总结/摘要、生图、看图/识图、语音识别（QQ 语音）、语音合成/发语音（F9DS 的 TTS+SILK）、联网搜索/抓取（DeepSeek 工具、抓取服务）、B站视频理解（抓取+本机 ASR）、文字识别/文档阅读、仓库读取（repo_*）、历史搜索/记忆/知识库/画像、表情包、定时任务、QQ 网关收发、MCP 桥……凡 src/ 里实际存在的都要有，不要凭空造）：
```
{ "capabilities": [ { "id","title","aliases":[],"tools":[],"how":"一句话链路（人写，准确）",
   "files":[{"path","anchor":"<正则，用于找行号>","role"}],
   "providers":[{"role","vendor","file","host_pattern":"api\\.openai\\.com","model_pattern":"gpt-image-[0-9a-z.-]+"}],
   "switches":["image_gen"],"requires_env":["OPENAI_API_KEY"],
   "runs_on":"cloud|local|both","local_component":"runner/asr.mjs",
   "limit":{"template":"每人每天 {n} 张","file":"src/imagegen.ts","pattern":"<正则，捕获组1是数字>"},
   "default_state":"on|off_by_default" } ],
  "vendors":[{"vendor":"DeepSeek","env_names":["DEEPSEEK_API_KEY"],"key_location":"Cloudflare Worker secret"}],
  "module_roles":{"src/semantic.ts":"可选：覆盖自动取的模块说明"},
  "uncovered_ok":["calc"] }
```
4. **校验（任何一条失败 → 打印原因并 exit 1）**：files[].path 存在且 anchor 能匹配（行号写入卡）；provider 的 host_pattern/model_pattern 必须在指定 file 里匹配到，卡里写**实际匹配到的字符串**（不是清单里的正则）；switches 里每个名字必须在 src/ 下以 `off:<名字>` 或 BotTool.switch/工具名形式出现；requires_env 每个名字必须在 src/ 或 runner/ 或 scripts/ 里出现；limit.pattern 必须匹配，数字取代 {n}；**每个已注册工具必须属于某个能力的 tools，或在 uncovered_ok 里**，反过来清单里写的工具名必须真实注册。
5. **repo_map**：top_dirs（顶层目录，role 取 module_roles 或内置一行说明）；modules（src/*.ts、src/tools/*.ts、runner/* 的路径、首个 `/** */` 或 `//` 注释第一行作 role、行数）；entrypoints（src/worker.ts 里 `export default` 的 fetch/queue/scheduled 的行号；runner 下各服务入口；scripts 下部署脚本）；tables（migrations/*.sql 里 CREATE TABLE 的表名与迁移文件名）；crons/queues/bindings（解析 wrangler.toml，只取名字，不读任何 secret）；repo 取 config/team.json 里 `OmnixSI/TeamAgent`（不得用 git remote）。
6. **密钥铁律**：只读 src/ runner/ scripts/ migrations/ config/team.json wrangler.toml package.json；绝不读 .env、.dev.vars、任何密钥文件、~/.ssh；输出里只允许环境变量**名**。生成结束前对整个输出跑 src/repo.ts 的 redactPatch 同类正则（可拷贝其 token 正则）和「值像密钥」扫描，命中即失败。
7. 幂等：同一提交重复生成，除 built_at 外输出一致；生成目录 src/ 之外不写文件。
