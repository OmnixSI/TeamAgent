# 云端读取 GitHub 仓库

群里可提供 owner/repo、GitHub 链接或团队仓库短名，查询文件、目录、文件名、最近提交和某次提交改动。
repo_file 支持 read/list/find；未给路径时列根目录，读取文件默认返回前 200 行，可指定行号和分支。
任意公开仓库可读；私有访问只限配置中的五个团队仓库，使用 Worker 已配置的只读 GitHub token。
文件先检查拒绝路径，再按固定提交读取树条目和 blob；符号链接只返回元信息，不读取目标。
敏感路径不展示，内容先脱敏；单文件上限 256000 字节，单次文本返回上限 12000 UTF-8 字节。
无 token 或 GitHub 临时不可用时，团队仓库提交查询可退回本机已同步索引；文件查询会说明缺少访问条件。
author 在云端按 GitHub 用户名或邮箱筛选；索引兜底按作者名称子串筛选。since 支持 24h/3d/7d 或 ISO 日期。
单独文件查询及与提交查询混批保持前台；混合网页检索或项目资料查询时沿用原后台处理规则。
每轮最多 10 次 GitHub 请求（含重定向），单次请求最多 5 秒，整个工具调用最多 8 秒，正文读取也计时。
本轮不提供源码上传、ZIP、内容搜索或本机自动克隆；不新增数据库表或路由。
