# 已拒绝的做法

- 每句群聊都回复。
- 主动发言按“10 分钟最多 3 次”或固定冷却限制。
- 把爆粗、热词、反问、emoji 当每条回复必填项。
- 进入思考或调用工具后变回长篇客服报告。
- 全天用 max 整理每句消息，挤占聊天。
- 把普通检索、游戏 ID 查询或引用旧回复反复排成资料任务。
- 向群里原样发送本机路径、命令和超时异常。
- 把研究原型、生成文件、单元测试、部署成功分别当成生产验收、附件已送达、24 小时在线的证据。
- 继续把团队 Agent 放在个人墨水屏仓库的 PR 中。
- 同一个 CI 故障每次提交、重跑或每个关联 job 都提醒；先发泛化提醒、再发同一个问题的初查。
